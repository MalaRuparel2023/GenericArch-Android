## Rules

- A memory row states **what was learned and what it changes**, not what was done.
- Anything that turns out to be a rule belongs in `CLAUDE.md` (with approval, §12); anything that
  turns out to be a settled choice belongs in `docs/DECISIONS.md`. Memory is for the rest.
- `androidArchVerifyMemory` checks this index against the directory — a file with no row is
  unreachable.
